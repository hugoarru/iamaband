# I am a band — website

The marketing, support and privacy pages for the I am a band app, served by GitHub Pages at <https://hugoarru.github.io/iamaband/>.

| Page | URL | Use in App Store Connect |
| --- | --- | --- |
| Home | `/iamaband/` | Marketing URL |
| Support | `/iamaband/support/` | Support URL |
| Privacy | `/iamaband/privacy/` | Privacy Policy URL |

Plain HTML and CSS, no build step. Pages publishes the `main` branch from the root.

When the app is live, replace the "Coming soon to the App Store" pill in `index.html` with a link to its App Store page (there's a comment next to it).

The Rubik font is under the SIL Open Font License, in `assets/fonts/OFL.txt`.
